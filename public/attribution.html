Data attribution & scope

LinguaRoute uses an 18-language subset of WiLI-2018 — Wikipedia Language Identification database, created by Martin Thoma, published January 7, 2018. The original database contains 235,000 Wikipedia paragraphs across 235 languages.

The publisher licenses the database under the Open Database License (ODbL) 1.0. Wikipedia text may also carry its underlying content attribution and share-alike requirements. The original source, database licence, and dataset documentation remain referenced in this project's data folder.

Changes made for this project: select 18 languages, normalize Unicode/whitespace, remove exact normalized training/test overlaps and duplicate training examples, then train a character TF-IDF classifier. Test labels are used only for reporting final results. The distributed selected-data files retain ODbL terms; no exclusive rights over the source dataset are claimed.

Reference: Thoma, M. (2018). The WiLI benchmark dataset for written language identification.

What the model does

It scores 18 known languages for a written passage and suggests a language desk. Sentence segments are independently scored to help a reviewer inspect language changes. It does not translate, identify a person's nationality, or reliably recognize every unknown language.

Evaluation uses Wikipedia paragraphs. It does not establish reliability for short chat messages, romanised languages, code-switching within a sentence, or current live customer content. Linear SVM scores are not probabilities. The review threshold reduces uncertain suggestions but is not a validated out-of-domain detector.

Privacy

Inference runs locally after the static model files load. The application sends no submitted text to a backend, stores no messages, and uses no paid inference API. Exporting creates a local CSV containing the messages you entered.

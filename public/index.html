Evaluation JSON ↗

Two methods, the same test set

Character TF-IDF features with a Naive Bayes baseline and a linear support vector machine. Hyperparameters were selected on training-validation data.

WiLI-2018 paragraphs in 18 selected languages. These scores do not measure chat accuracy, romanised Hindi, or unseen languages.

Know when to ask a reader

Very short text, weak scores, close alternatives, or unfamiliar patterns trigger review. The score and gap thresholds were chosen on validation data.

A high score is not certainty. Unknown languages can still be assigned a supported language. Human review remains necessary.

04 / THE NLP INSIDE

Look for patterns, not a dictionary.

01

Preserve the script

Normalize Unicode and whitespace, then lowercase. Accents and scripts remain meaningful features.

02

Read small patterns

Character groups of 2–4 symbols capture spelling habits, endings, and shared language patterns.

03

Weight and compare

TF-IDF weights the patterns. A linear SVM scores 18 candidate languages using learned weights.

04

Route transparently

Inspect the alternatives and influential patterns. Flag ambiguous segments for a human reader.

SUPPORTED LANGUAGES

A focused, measurable scope.

Best for natural paragraphs in their usual scripts. Mixed words within one sentence, transliteration, spelling noise, lists of names and languages outside this set are not validated. The overall result uses the first 3,000 characters; the sentence map examines up to 80 segments.
